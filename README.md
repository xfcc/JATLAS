# JATLAS

JATLAS 是一个为 NAS 和 Emby 用户设计的私人影片收藏台账。NAS 保存文件，Emby 负责识别和播放，JATLAS 记录每位演员和每个分类有多少部影片，以及哪些收藏已经超出你设定的上限。

[产品官网](https://jatlas-six.vercel.app/) · [下载桌面版](https://github.com/xfcc/JATLAS/releases/latest)

## JATLAS 能做什么

- **按分类设上限。** 为每个分类设置单人影片上限和分类总量上限，把更多空间留给你更在意的收藏。
- **从 NAS 导入已有收藏。** 为分类指定目录，扫描其中的一级文件夹，批量导入还没建档的演员。
- **与 Emby 核对影片数量。** 补全演员的 Emby ID，再为单个演员或整个分类刷新影片数量。一个演员可以关联多个 Emby ID。数量增加时更新资产扩增时间，数量减少时同样更新台账里的影片数。
- **查看超限和长期未扩增的收藏。** 资产总览提供影片总量、单人超限和分类压力。近六个月的月表列出新增演员，以及刷新影片数量带来的入库与出库。
- **维护演员档案。** 保存头像、别名、出生日期、出演时间和标签，也可以从 Minnano 获取资料，核对后再保存。现役和引退状态由出演结束时间自动判断。
- **在操作日志里查结果。** 查看本次打开应用期间的扫描、导入、同步和资料变更记录。批量任务可以取消，Emby 同步的失败项可以重试。

## 从已有收藏开始

1. 按自己的保留意愿建立分类，设置单人上限和分类总量上限。
2. 为分类指定 NAS 目录，扫描文件夹并导入演员。
3. 补全 Emby ID，刷新影片数量。
4. 在资产总览里找到压力较高的分类，再查看具体哪些演员超限或长期未扩增。

## 数据保存在本机

JATLAS 是桌面应用，台账保存在本机，核心流程无需账号。目录扫描只读取文件夹。分类调整和演员维护只修改台账，影片仍由你在 NAS 或 Emby 中管理。
